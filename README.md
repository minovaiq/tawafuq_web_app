# توافقات Web

تطبيق ويب عربي مستقل للمستخدمين بنفس الهوية البنفسجية.

- بدون تسجيل دخول.
- الشركات والأجهزة والتوافقات المعتمدة تُقرأ من Supabase.
- إرسال التوافقات يتم عبر الدالة `tawafuq_submit_public` وتُسجّل `pending` للمراجعة من لوحة التحكم.
- لا توجد بيانات تجريبية داخل الواجهة.

للتشغيل: ارفع الملفات على استضافة HTTPS ثابتة، أو شغّل خادم محلي داخل المجلد `python -m http.server 8000`.

**تنبيه:** إرسال الاقتراحات متاح للزوار؛ يُنصح بإضافة حماية ضد الإرسال الآلي (CAPTCHA/حد معدل الطلبات) قبل نشر التطبيق للعامة.


## شعارات الشركات
ملفات SVG الأصلية في images/brands. تم ربط سبعة شركات موجودة في قاعدة البيانات بمسارات نسبية. يجب نشر مجلد images كاملاً مع الموقع. ملفات HTC وLG وLenovo مضافة كأصول جاهزة لكن لم تُنشأ شركات جديدة في قاعدة البيانات.

تحديث الواجهة: إخفاء مسار التنقل والتنبيهات الخاصة بحفظ وتحديث البيانات دون تغيير عمل التخزين المحلي.

## تحسين سرعة شعارات الشركات
الشعارات المتوفرة محلياً تُحمّل من كاش التطبيق مباشرة، والشعارات الظاهرة لا تنتظر lazy-loading. تحديث كاش التطبيق إلى v11.

## تسريع صور الشركات v12
أصبحت جميع الشعارات المدعومة ملفات محلية، بدون تحميل من روابط خارجية. الشركات التي لم تتوفر لها شعارات أصلية تستعمل علامات نصية محلية مؤقتة. الكاش يحدث إلى v12.
